# Combined, pinned dependency set for running backend/ + bot/ on a regular PC
# (Linux/macOS/Windows x86_64), with no Raspberry Pi or camera hardware involved.
#
# Generated from a real install + boot test on 2026-08-17, including a live
# end-to-end pose-detection check (webcam -> backend -> MediaPipe -> skeleton
# drawn -> /video/output).
#
# mediapipe is pinned to 0.10.14 on purpose: mediapipe>=1.0 removed the
# legacy `mediapipe.solutions` API that posture_monitor.py depends on
# (mp.solutions.pose). Anything >=1.0 breaks PostureMonitor with
# "AttributeError: module 'mediapipe' has no attribute 'solutions'".
#
# This file is a superset of backend/requirements.txt + bot/requirements.txt,
# resolved together in one virtualenv so both services can share it.
# It intentionally excludes picamera2 (modo-ap/test_websocket.py), which only
# runs on a Raspberry Pi with a camera attached.
#
# Usage:
#   python3 -m venv .venv && source .venv/bin/activate
#   pip install -r requirements-pc.txt
